## 個別の注意

- 機械の情報リテラシー（p12）は059番の記載がなく、隣接範囲を結合していない。
- 数情の線形代数学（p8）は明示された名簿を採用。JABEEから転コースした学生は担任に確認するという脚注があるため、画面でも個別指定の確認を促す。
- キャリアデザインは添付資料に掲載されていない。時間割の開講Qを表示し、手動選択を残す。
- 現行時間割と不一致の科目は時間割をPDFで上書きせず、自動判定から除く。
- 科目の一部クラスだけが保留の場合、確定済み番号の別クラスは使用可能。対応を確認できない番号は手動確認とし、単一候補から推測しない。

## 改訂時の手順

1. 新しい公式表の年度・ページ・更新内容を確認する。番号の範囲・欠番・科目別の例外を画像と照合する。
2. 講義コード・開講Q・曜日時限を現行の時間割に照合し、担当教員の変更や矛盾は保留する。
3. `rules` と `coveredCourseKeys`、`reviewNotes` を更新し、確認日・原本SHA-256を記録する。
4. `npm test`、`npm run check`、`npm run build` を実行してGitHubへpush・PR作成する。

時間割Excelの定期取得だけではクラス分け表を更新しない。Excel側で講義の意味が変わった場合は実行時に照合を失敗させ、自動選択を止める。
