# 単位数が未設定の科目一覧（2026年度）

確認日：2026年9月11日

この一覧は、履修登録シミュレータの取り込みデータで単位数を確認できていない科目を整理したものです。**大学で単位数が未決定という意味ではありません。** 時間割・授業科目表・シラバスなどの正式な資料で値を確認してから、アプリのデータを補完するために使用します。

初習外国語（ドイツ語・フランス語・中国語）の全16講義を1単位に修正した状態を対象としています。

## 集計の範囲と数え方

- 対象は[2026年度の科目データ](../src/data/course-data.json)にある全1,720講義です。前期・後期・通年・集中講義、および1～4年生向けの科目を含みます。
- 未設定とは、[学科との適合判定](../src/course-compatibility.ts)を通る学科の少なくとも一つで、`creditsByDepartment[学科] ?? defaultCredits` が `null` になることです。今回残った科目は、適合するすべての学科で単位数が未設定でした。
- 残件は **228講義コード・180名称** です。「名称」はデータの正規化済み `key` の種類数です。A・Bクラス、グループ、特設などの付記が異なるものは、そのまま別名称として数えています。
- 学科別の同名科目は講義コードが別です。下表の区分ごとの名称数を足すと193になりますが、区分をまたいで重なる名称があるため、全体の名称数は180です。
- 下の一覧では同じ区分・同じ `key` を一行にまとめ、該当する設置学年・開講期間・講義コードをすべて並べています。設置学年は履修候補の表示に使用するデータ上の年次です。

**名前が似た科目から単位数を自動補完していません。** 「特設」などの原表の付記は保持し、通常クラスと同一の単位数だとは推定していません。A・Bクラス、グループ、コース別の名称も、正式な資料との対応を確認してから補完する必要があります。
